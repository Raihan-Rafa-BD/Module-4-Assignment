# Problem # 02
# Python Dictionary to JSON string:
# Description:
  This project demonstrates how to convert a Python dictionary into a JSON-formatted string using Python's built-in json module.
# Requirements
    Python 3.x
    No external libraries are required because json is included in Python's standard library.

# How It Works
    The json module is imported.
    A Python dictionary named student is created with the student's name, age, and department.
    json.dumps() converts the Python dictionary into a JSON string.
    print() displays the resulting JSON string.

# Output:
  {"name": "Rahim", "age": 20, "department": "CSE"}

# Run the Program:
  python studentinfo.py

# Output:
  {"name": "Rahim", "age": 20, "department": "CSE"}
# Key Function:
json.dumps()
json.dumps() converts a Python object, such as a dictionary, into a JSON-formatted string.
